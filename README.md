# Комната 90-х — прототип (Marat Suleimanov · EP)

Промо-сайт EP: горизонтальная «комната в стиле 90-х», где можно тыкать в предметы,
и они оживают. В центре — реальный жёлтый телевизор «Сапфир 401-1».

**Живая версия:** см. GitHub Pages этого репозитория.

## Что внутри
- Обои, пол, табуретка, вырезанный телевизор на прозрачном фоне.
- Экран: помехи + шипение, аффорданс «нажми», переключение «каналов»
  (полосы SMPTE, заставка EP, бегущая строка, «нет сигнала»).
- Панель управления (реальные кнопки «Юности»): 5 кнопок-каналов + тумблер питания.
- Два кликабельных предмета: вымпел «Ударнику соцтруда» (качается + «ба-дум тссс»)
  и часы с кукушкой («ку-ку»).
- Весь звук синтезируется в браузере через Web Audio API (без аудиофайлов).
- На вертикальных экранах — оверлей «поверни телефон».

## Стек
Чистые HTML/CSS/JS, без зависимостей. Открывается как статика.

## Заметки
- Реальных видео для экрана пока нет — «каналы» это заглушки; синий экран телека
  на фото уже готов как хромакей под будущие ролики.
- Ассеты вырезаны через `rembg` (см. `tools/process.py`); `tools/venv` и `tools/src`
  в репозиторий не входят.
