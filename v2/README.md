# Комната 90-х — v2, светлая (Marat Suleimanov · EP)

Эксперимент поверх версии в корне репозитория. Тот же промо-сайт EP, но комната
**светлая и весёлая**, а телевизор «Сапфир 401-1» стоит **лицом к зрителю**.

Оригинал в корне не тронут и живёт по прежнему адресу.

## Что изменилось против v1

- **Обои.** Тот же дамаск, перекрашенный в пастель: мятно-бирюзовый орнамент
  на молочном фоне (`tools/recolor_wall.py` → `assets/wall.png`). Заодно
  выровнен неравномерный свет исходной фотографии и сшит бесшовный раппорт —
  на светлой стене швы фотоснимка было бы видно полосами.
- **Свет в комнате.** Фиолетовый сумеречный `multiply`-грейд заменён на мягкий
  дневной свет из окна слева (`soft-light`). Пол — светлый паркет досками
  вглубь, добавлен плинтус. Табуретка — светлое дерево, вся геометрия в % от
  сцены (в px ножки уезжали за нижний край кадра).
- **Телевизор в фас.** Вырезан заново из `картинки/новый ТВ/best.HEIC`
  (`tools/tv_front.py` → `assets/tv.png`). Экран-хромакей теперь смотрит прямо,
  без перспективной трапеции.
- **Экран — бокс, а не clip-path.** `.screen` спозиционирован ровно по окну
  телевизора (`left/top/width/height` + `border-radius`). Через `clip-path`
  поверх полноразмерного слоя контент канала растягивался на весь корпус и
  обрезался — у полос SMPTE пропадали красная и синяя.
- Экран остался тёмным: CRT, помехи и свечение работают именно на контрасте
  со светлой комнатой.

`app.js` не менялся — логика каналов, Web Audio и анимации от геометрии не зависят.

## Инструменты

```
tools/recolor_wall.py   светлые обои     -> assets/wall.png
tools/tv_front.py       телевизор в фас  -> assets/tv.png
```

Вырезка v1 — в `../tools/process.py` (боковой ракурс телевизора, часы).

Запуск тем же окружением, что и v1 (venv в репозиторий не входит):

```
../tools/venv/bin/python tools/tv_front.py
```

`tv_front.py` кэширует промежуточные файлы в `tools/src/` — чтобы перегнать
заново, удалите `tools/src/tv_front_*.png`.

## Локально

```
python3 -m http.server 8080
```

Дальше как в v1: чистые HTML/CSS/JS, без зависимостей; на вертикальных экранах —
оверлей «поверни телефон»; реальных роликов для экрана пока нет, «каналы» это
заглушки под будущее видео на синем хромакее.
